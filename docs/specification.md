# Modbus TCP対応 DIOモジュール 仕様書ドラフト

## 1. 概要

本モジュールは、Modbus TCPにより制御可能なDIOモジュールである。

本モジュールは以下の入出力を備える。

| 項目 | 内容 |
| --- | --- |
| デジタル入力 | 16ch |
| デジタル出力 | 16ch |
| 通信方式 | Modbus TCP |
| 内部制御周期 | 100Hz |
| 基本更新周期 | 10ms |

デジタル入力は、内部的にはアナログ入力としてADCにより取得される。
デジタル出力は、電圧出力モードおよびリレー接点相当モードを備える。

---

## 2. デジタル入力仕様

### 2.1 入力チャンネル数

本モジュールは、16チャンネルのデジタル入力を備える。

- DI0 ～ DI15

各デジタル入力は、内部的にはアナログ入力として取得される。

### 2.2 入力取得周期

各入力チャンネルは、100Hz周期でポーリングされる。

- ポーリング周期: 100Hz
- 更新間隔: 10ms

取得された値は、対応するModbusレジスタへ反映される。

### 2.3 入力基準電圧

デジタル入力は、設定された基準電圧に対する割合として扱う。

- 0% = 0V相当
- 100% = 設定された入力基準電圧相当

入力電圧が設定基準電圧を超える場合、入力値は100%に飽和する。

### 2.4 基準電圧設定

入力基準電圧は、4チャンネルごとのバンク単位で設定する。
設定は基板上のDIPスイッチにより行う。

| 入力チャンネル | バンク |
| --- | --- |
| DI0 ～ DI3 | Input Bank 0 |
| DI4 ～ DI7 | Input Bank 1 |
| DI8 ～ DI11 | Input Bank 2 |
| DI12 ～ DI15 | Input Bank 3 |

各バンクで選択可能な入力基準電圧は以下とする。

| 設定 | 入力基準電圧 |
| --- | --- |
| 0 | 3.3V |
| 1 | 5V |
| 2 | 12V |
| 3 | 24V |

### 2.5 入力値の例

| 入力基準電圧設定 | 実入力電圧 | 入力値 |
| --- | --- | --- |
| 3.3V | 0V | 0% |
| 3.3V | 1.65V | 50% |
| 3.3V | 3.3V | 100% |
| 3.3V | 5V以上 | 100% |
| 5V | 2.5V | 50% |
| 5V | 5V | 100% |
| 12V | 6V | 50% |
| 12V | 12V | 100% |
| 24V | 12V | 50% |
| 24V | 24V | 100% |

### 2.6 Modbusレジスタ表現

各入力チャンネルは、1つの16bit Modbusレジスタに対応する。

入力値は、1カウント = 1%のスケーリングで表現する。

- 0 = 0%
- 100 = 100%

例：

| 入力状態 | レジスタ値 |
| --- | --- |
| 0% | 0 |
| 50% | 50 |
| 100% | 100 |

入力電圧が基準電圧を超える場合、レジスタ値は100に飽和する。

## 3. デジタル出力仕様

### 3.1 出力チャンネル数

本モジュールは、16チャンネルのデジタル出力を備える。

- DO0 ～ DO15

### 3.2 出力更新周期

各出力チャンネルは、100Hz周期で状態を更新可能とする。

- 更新周期: 100Hz
- 更新間隔: 10ms

### 3.3 絶縁

デジタル出力回路は、マイコン側制御回路と外部出力端子側の間を絶縁する。
絶縁にはフォトリレー、または同等の絶縁型半導体リレー素子を用いる。

### 3.4 出力端子構成

各出力チャンネルは、1ポートあたり2端子を持つ。

- DOx_A
- DOx_B

### 3.5 出力モード設定

出力モードは、4チャンネルごとのバンク単位で設定可能とする。
設定は基板上のDIPスイッチにより行う。

| 出力チャンネル | バンク |
| --- | --- |
| DO0 ～ DO3 | Output Bank 0 |
| DO4 ～ DO7 | Output Bank 1 |
| DO8 ～ DO11 | Output Bank 2 |
| DO12 ～ DO15 | Output Bank 3 |

各バンクは、3bit分のDIPスイッチ設定により、出力モードを選択する。

### 3.6 出力モード

各バンクで選択可能な出力モードは以下とする。

| モード | 出力動作 |
| --- | --- |
| 3.3V出力モード | 出力ON時に内部生成した3.3Vを出力する |
| 5V出力モード | 出力ON時に内部生成した5Vを出力する |
| 12V出力モード | 出力ON時に内部生成した12Vを出力する |
| 24V出力モード | 出力ON時に内部生成した24Vを出力する |
| リレー接点モード | 出力ON時にDOx_A-DOx_B間を短絡相当、出力OFF時に開放相当とする |

電圧出力モードでは、出力電圧はモジュール内部で生成する。
外部出力端子には、DIPスイッチで選択された内部生成電圧を出力する。

### 3.7 電圧出力モードの端子動作

電圧出力モードにおける端子動作は以下とする。

- ON時: DOx_A = 選択電圧、DOx_B = 出力基準GND
- OFF時: DOx_A = Low相当、DOx_B = 出力基準GND

### 3.8 リレー接点モードの端子動作

リレー接点モードでは、DOx_A-DOx_B間は無電圧接点相当として動作する。

- ON時: DOx_A-DOx_B間を短絡相当
- OFF時: DOx_A-DOx_B間を開放相当

このため、外部配線により以下のような用途に使用可能とする。

- PNP相当出力
- NPN相当出力
- 接点入力の模擬
- 外部回路の単純な開閉制御

### 3.9 出力電流

各デジタル出力ポートの最大出力電流は以下とする。

- 最大出力電流: 500mA / port

電圧出力モードでは、各出力ポートは選択された内部生成電圧において最大500mAまでの負荷を駆動可能とする。

| 出力モード | 最大出力電流 |
| --- | --- |
| 3.3V出力モード | 500mA / port |
| 5V出力モード | 500mA / port |
| 12V出力モード | 500mA / port |
| 24V出力モード | 500mA / port |

リレー接点モードでは、DOx_A-DOx_B間の短絡相当経路における最大許容電流を500mA / portとする。

複数ポートを同時に使用する場合、内部電源回路および基板配線の総電流定格を超えないこと。

## 4. Modbus TCP仕様

### 4.1 通信方式

本モジュールは、Modbus TCPにより外部ホストから制御および状態取得を行う。

### 4.2 レジスタアドレス表記

本仕様書では、Modbus PDU上で使用する0始まりのアドレスを正式なレジスタアドレスとして扱う。

| 表記 | 内容 | 例 |
| --- | --- | --- |
| Protocol Address | Modbus PDUで指定する0始まりのアドレス | `0x0000` |
| Decimal Address | Protocol Addressの10進表記 | `0` |
| Reference No. | PCツール等で表示されることが多い1始まりの参照番号 | Input Registerの場合 `30001`、Holding Registerの場合 `40001` |

PCツールにより、レジスタ番号を0始まりで入力するものと、`30001` / `40001` のような1始まりの参照番号で入力するものがある。
実装および通信試験では、Protocol Addressを基準として扱う。

### 4.3 対応Function Code

初期仕様では、ビット単位のCoil / Discrete Inputは使用せず、16bitレジスタに集約して扱う。

| 用途 | レジスタ種別 | Function Code | アクセス | 備考 |
| --- | --- | --- | --- | --- |
| DI入力値読出し | Input Register | `0x04` Read Input Registers | Read Only | 100Hz周期で更新される値を含む |
| DO制御値の単一書込み | Holding Register | `0x06` Write Single Register | Write | 1ch単位の制御に使用する |
| DO制御値の複数書込み | Holding Register | `0x10` Write Multiple Registers | Write | 複数chの同期点滅設定に使用する |

#### 4.4.2 DI入力値レジスタ

`DI0_PERCENT` ～ `DI15_PERCENT` は、入力基準電圧に対する入力電圧の割合を1カウント = 1%で表す。

- `0` = 0%
- `100` = 100%

入力電圧が設定基準電圧を超える場合、対応するDI入力値レジスタは`100`に飽和する。

#### 4.4.3 システム時刻レジスタ

`SYSTEM_TIME_HIGH` と `SYSTEM_TIME_LOW` は、32bit unsigned値を上位16bit、下位16bitの順で表す。

```text
SystemTimeCounter = (SYSTEM_TIME_HIGH << 16) | SYSTEM_TIME_LOW
```

`SYSTEM_TIME_HIGH` と `SYSTEM_TIME_LOW` を同一のRead Input Registers要求で読み出した場合、同一タイミングのスナップショット値を返す。
個別に読み出した場合は、2回の読出し間でカウンタが更新される可能性がある。

#### 4.5.2 DO制御レジスタ値の有効範囲

`DO0_CONTROL` ～ `DO15_CONTROL` に書込み可能な値は以下とする。

| 条件 | 意味 | 書込み可否 |
| --- | --- | --- |
| `0` | 固定LOW | 可 |
| `1` | 固定HIGH | 可 |
| bit0 = `1` かつ bit1～6のいずれかが`1` かつ bit7～15 = `0` | 自動点滅 | 可 |
| 上記以外 | 予約値 | 不可 |

予約値が書き込まれた場合、対象レジスタおよび出力状態は変更せず、Modbus例外応答 `0x03` Illegal Data Valueを返す。

#### 4.5.3 複数レジスタ書込み時の扱い

`Write Multiple Registers`で複数のDO制御レジスタを書き込む場合、要求内に予約値が1つでも含まれると、その要求全体を不受理とする。
この場合、対象範囲の制御レジスタおよび出力状態は変更せず、Modbus例外応答 `0x03` Illegal Data Valueを返す。

複数の自動点滅設定が同一の`Write Multiple Registers`要求で受理された場合、それらの設定は次回の100Hz更新タイミングでまとめて反映する。

## 5. デジタル出力レジスタ仕様

### 5.1 基本動作

| レジスタ値 | 動作 |
| --- | --- |
| 0 | 固定LOW |
| 1 | 固定HIGH |
| bit0 = 1 かつ bit1～6 に時間指定あり | 自動点滅 |

固定LOW時は、電圧出力モードではLOW相当を出力し、リレー接点モードでは開放とする。

固定HIGH時は、電圧出力モードでは選択された出力電圧を出力し、リレー接点モードでは短絡とする。

### 5.2 自動点滅モード

自動点滅モードでは、bit1～3をLOW時間、bit4～6をHIGH時間として扱う。

| ビット | 内容 |
| --- | --- |
| bit0 | 自動点滅指定ビット |
| bit1～3 | LOW時間設定 |
| bit4～6 | HIGH時間設定 |
| bit7～15 | 予約 |

LOW時間およびHIGH時間の単位は0.1秒とする。

- LOW時間 = bit1～3 の値 × 0.1秒
- HIGH時間 = bit4～6 の値 × 0.1秒

ただし、レジスタ値が0の場合は固定LOW、レジスタ値が1の場合は固定HIGHとして扱う。

そのため、自動点滅モードは以下の条件で有効とする。

- bit0 = 1
- かつ bit1～6 のいずれかに時間指定がある

### 5.3 自動点滅モードの例

| レジスタ値 | bit6～bit0 | LOW時間 | HIGH時間 | 動作 |
| --- | --- | --- | --- | --- |
| 0 | 0000000 | - | - | 固定LOW |
| 1 | 0000001 | - | - | 固定HIGH |
| 23 | 0010111 | 0.3秒 | 0.1秒 | 自動点滅 |
| 55 | 0110111 | 0.3秒 | 0.3秒 | 自動点滅 |
| 101 | 1100101 | 0.2秒 | 0.6秒 | 自動点滅 |

自動点滅モードでは、上位ホストが周期的にON/OFFを書き換える必要はない。
一度レジスタにLOW時間およびHIGH時間を設定すると、モジュール内部で指定周期に従って出力を切り替える。

### 5.4 Modbus書き込み時の出力反映タイミング

デジタル出力制御レジスタに対するModbus書き込みは、レジスタ値の内容に応じて反映タイミングを分ける。

#### 固定出力指定時

書き込まれたレジスタ値が以下の場合、出力状態は即時反映する。

| レジスタ値 | 動作 | 反映タイミング |
| --- | --- | --- |
| 0 | 固定LOW | 即時反映 |
| 1 | 固定HIGH | 即時反映 |

固定LOWまたは固定HIGH指定時は、Modbus書き込み受信後、可能な限り速やかに対象出力へ反映する。

#### 自動点滅指定時

書き込まれたレジスタ値が自動点滅指定の場合、出力設定は100Hz周期の内部更新タイミングで反映する。

自動点滅指定は以下の条件で判定する。

- bit0 = 1
- かつ bit1～6 のいずれかに時間指定がある

自動点滅設定は、内部100Hz更新周期に同期して反映する。

- 反映周期: 100Hz
- 反映間隔: 10ms

#### 複数出力の同期反映

複数の出力レジスタが自動点滅指定として書き込まれた場合、それらの設定は次回の100Hz更新タイミングでまとめて反映する。

これにより、複数チャンネルを連動させた点滅制御において、出力開始タイミングを揃えることができる。

例として、RGB LEDのR/G/B各チャンネルを同時に制御し、黄色点滅などの複数チャンネル同期出力を行う場合、各チャンネルの点滅設定は100Hz周期に同期して反映される。

#### 反映タイミングのまとめ

| 書き込み内容 | 反映タイミング |
| --- | --- |
| 固定LOW、レジスタ値0 | 即時反映 |
| 固定HIGH、レジスタ値1 | 即時反映 |
| 自動点滅設定 | 次回100Hz周期で反映 |

## 6. システム時刻カウンタ仕様

### 6.1 概要

本モジュールは、起動後の経過時間を示す32bitカウンタを持つ。

カウンタは、モジュール起動時に0で初期化される。
以後、内部周期100Hzに同期して、0.01秒ごとに1カウント加算される。

- 1 count = 0.01秒
- 更新周期 = 100Hz

### 6.2 Modbusレジスタ表現

カウンタ値は、Modbus上では連続する2つの16bitレジスタを用いて32bit unsigned値として扱う。

PC側および上位ホスト側からの読み取りやすさを考慮し、先頭レジスタを上位16bit、次レジスタを下位16bitとする。

- SystemTimeCounter_High: 上位16bit
- SystemTimeCounter_Low: 下位16bit

32bitカウンタの値は以下で表される。

```text
SystemTimeCounter = (SystemTimeCounter_High << 16) | SystemTimeCounter_Low
```

### 6.3 カウント範囲

カウント範囲は以下とする。

- 0 ～ 4,294,967,295

最大値に達した後、次のカウントで0に戻る。

```text
4,294,967,295 → 0
```

最大カウント時間は以下とする。

```text
4,294,967,295 × 0.01秒 = 42,949,672.95秒
```

これは約497.1日、約1.36年に相当する。

本レジスタは読み取り専用とする。
