# 回路設計検討メモ

## 1. 目的

本ドキュメントは、Modbus TCP対応DIOモジュールの回路設計に関する検討事項を整理するためのメモである。

詳細仕様は、[Modbus TCP対応 DIOモジュール 仕様書ドラフト](specification.md)を参照する。

## 2. システム構成案

本モジュールは、以下の主要ブロックで構成する想定とする。

| ブロック | 内容 | 状態 |
| --- | --- | --- |
| マイコン / Ethernet | Modbus TCP通信、DI計測、DO制御、内部100Hz周期処理 | WT32-ETHを使用予定 |
| DI入力回路 | 16ch入力、ADC入力向けの分圧・保護・レンジ切替 | 検討中 |
| DO出力回路 | 16ch出力、電圧出力モードおよびリレー接点相当モード | 検討中 |
| DO Source電源 | DO電圧出力モード向けの内部生成電源 | MP1584ENが候補 |
| 絶縁回路 | マイコン側制御回路と外部出力端子側の絶縁 | 検討中 |
| DIPスイッチ | DI入力基準電圧、DO出力モードのバンク設定 | 検討中 |

## 3. マイコン / Ethernet

マイコンおよびEthernet通信部には、WT32-ETHを使用する予定とする。

WT32-ETHは、以下の用途を担当する想定である。

- Modbus TCP通信処理
- 16ch DI入力値の取得およびModbus Input Registerへの反映
- 16ch DO制御レジスタの受信および出力制御
- 自動点滅モードの内部処理
- 100Hz内部制御周期の管理
- 起動後システム時刻カウンタの管理

## 4. DO Source電源

DO Source電源は、電圧出力モードにおいて外部出力端子へ供給する内部生成電圧の供給源である。

DO Source電源の候補として、MP1584ENを検討する。

### 4.1 MP1584EN採用検討の位置づけ

現時点では、MP1584ENは候補部品であり、正式採用は未決定とする。

今後、以下の観点で適合性を確認する。

- 入力電源電圧範囲
- 3.3V / 5V / 12V / 24V出力生成への適合性
- 1ポート最大500mA出力時の電流余裕
- 複数ポート同時使用時の合計電流余裕
- 発熱および基板放熱設計
- スイッチングノイズがDI ADC計測へ与える影響
- 絶縁構成および出力GND設計との整合性
- 保護回路、短絡保護、過電流保護との組み合わせ

### 4.2 DO Sourceで生成する電圧

仕様上、DO電圧出力モードでは以下の内部生成電圧を使用する。

| DO出力モード | 内部生成電圧 |
| --- | --- |
| 3.3V出力モード | 3.3V |
| 5V出力モード | 5V |
| 12V出力モード | 12V |
| 24V出力モード | 24V |

MP1584ENを採用する場合、単一構成で全電圧を生成するのか、複数の電源系統を設けるのかを今後決定する。

## 5. DI入力回路検討

DI入力は内部的にはADCで取得するため、各入力レンジに応じた分圧・保護回路が必要となる。

検討項目は以下とする。

- 3.3V / 5V / 12V / 24V入力基準電圧への対応
- DIPスイッチによる4chバンク単位のレンジ切替方式
- ADC入力電圧範囲への変換方式
- 入力過電圧保護
- 逆接続保護
- サージ / ESD耐性
- ADC計測精度および抵抗誤差の扱い
- 入力フィルタ定数と100Hz取得周期との整合性

## 6. DO出力回路検討

DO出力は、電圧出力モードとリレー接点相当モードを切り替えられる構成とする。

検討項目は以下とする。

- 4chバンク単位の出力モード切替方式
- DIP設定 `000` / `001` / `010` / `011` / `1xx` の回路反映方法
- 電圧出力モード時のHigh側スイッチ構成
- OFF時のLow相当出力方式
- リレー接点モード時の無電圧接点相当構成
- フォトリレーまたは同等の絶縁型半導体リレー素子の選定
- 1ポート最大500mAへの対応
- 複数ポート同時使用時の総電流制限
- 短絡保護および過電流保護
